# 🧥 服装行业 AI 趋势分析 Agent

一个支持数据上传、AI 自动分析、自由提问的服装行业智能助手。

## 功能

- 📊 **上传数据**：支持 CSV / Excel 格式
- 📈 **趋势分析**：AI 自动生成销售趋势分析报告
- 💬 **自由提问**：对数据随意提问，AI 基于数据回答
- 🔧 **技能调用**：Agent 自主决策调用分析工具（Function Calling）

## 快速开始

```bash
pip install openai pandas streamlit matplotlib openpyxl
streamlit run web_demo_v4.py
```

## 技术栈

Python · OpenAI SDK · DeepSeek · Streamlit · Pandas · Matplotlib
